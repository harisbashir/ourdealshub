# Project instructions

Read `CLAUDE.md` for architecture, commands, compliance and authorization rules.

Use the installed **apple-design** skill for every UI/UX change or review, as
requested by the project owner. Follow the existing semantic theme tokens,
44px touch targets, readable type, accessibility and reduced-motion rules.

Keep the app compatible with Hostinger managed Node 22 + MariaDB hosting.
Use finite scheduled scripts for social delivery; do not add persistent workers.
Deployment instructions are in `docs/DEPLOY.md`, `docs/VM.md` and `docs/SOCIAL.md`.
